# 盲道占用检测系统 · Blindway Grand

> 用普通摄像头 + AI 自动发现车辆占用盲道，并生成**带车辆特征的执法证据**。

**在线界面演示** → **https://snowcode-a.github.io/blindway-grand/**

---

## 这是什么

盲道是视障人士出行的"路标"，但被电动车、共享单车、机动车占用是城市顽疾。
人工巡查覆盖不了、成本高；普通摄像头只会录像，**不会判断**"车停在盲道旁边"
和"车压在盲道上"的区别。

本系统用一路普通摄像头就能自动发现占用行为，并留下可用于执法/劝导的证据图。

**点开上面的链接就能看到完整界面**（四个页面、检测画面、报警记录、数据报告），
无需安装任何东西。

---

## 技术亮点

### 1. 判定的是"车辆底边中点是否落在盲道区域内"，不是用检测框求交叠

这是本项目的核心。检测框会覆盖大片背景，如果直接用框和区域算交叠，
**停在盲道旁边的车也会被误判成占用**。取**底边中点**（车轮着地点）
才是车辆真正压在地面的位置，误报大幅下降。

### 2. 不看"路过"，只看"占用"

目标需连续 3 帧落在区域内（`confirm_frames`）才确认进入，
且停留超过 1.0 秒阈值才报警 —— 骑车人快速经过不会误报。

### 3. 用 BoT-SORT 做相机运动补偿

实拍手持视频对比：ByteTrack 39 帧有效追踪 → BoT-SORT **205 帧（+426%）**，
静态场景也提升 +2%，速度几乎不变。

### 4. 同一辆车在一次连续占用中只报警一次

去重键为追踪 ID，离开区域后重新驶入才会再次报警。

### 5. 盲道区域由人工标定

不同路段的盲道形态差异极大（有砖、有涂料、有被磨掉的），自动识别不稳定。
人工拖 4 个角点 10 秒完成，且 **100% 可靠** —— 在执法场景里，"可靠"比"自动"重要。

## 实测数据

| 指标 | 数值 |
|---|---|
| 检测速度 | **51~71 ms/帧**（纯 CPU，无显卡） |
| 车牌识别 | 约 7 ms/次 |
| 演示视频有效检测 | 141 帧中 116~139 帧检测到目标落在盲道区域内 |
| 停留判定阈值 | 1.0 秒（确认帧数 3 帧） |
| 车牌防误报 | 双重校验（严格中国车牌格式 + 置信度 ≥ 0.70），10/10 测试用例正确 |
| 代码规模 | 约 5500 行（界面 + 检测引擎 + 取证模块 + 自检脚本） |

> 关于车牌：**宁可不识别，也不编造车牌号**。演示视频里车辆多无牌或角度不可读，
> 系统如实输出"未识别"，并记录车身颜色 + 车型作为替代特征。

## 四个功能页面

1. **实时监控** — 检测画面 + 区域内目标表 + 实时统计 + 参数在线调节
2. **区域标定** — 在画面上拖动 4 个角点框出盲道，保存后立即生效
3. **报警记录** — 报警明细表 + 证据大图（可缩放看车牌）+ CSV 导出
4. **数据报告** — 处理帧数 / 报警次数 / 最长停留 / 占用占比 + 停留时长柱状图

### 证据图里有什么

```
┌──────────────────────────┬─────────────────┐
│                          │  车辆放大特写    │
│   报警时刻原图            │                 │
│   （红框标出涉事车辆）     │  车牌号 / 车牌类型│
│                          │  车身颜色 / 车型  │
│                          │  停留时长 / 时间  │
│                          │  帧号 / 监测地点  │
├──────────────────────────┴─────────────────┤
│  判定依据：车辆底边中点落在盲道 ROI 内       │
│            且停留超过阈值 -> 判定为占用      │
└────────────────────────────────────────────┘
```

## 关于本仓库

本仓库包含**两部分**：

### 一、在线界面演示（GitHub Pages）

静态站点，**无需安装任何东西**，点开链接就能看到完整界面（四个页面可切换）。

```
├── index.html          界面演示
├── assets/             样式、脚本、真实检测素材
├── .nojekyll           让 Pages 原样发布
└── 发布.ps1            一键发布脚本
```

### 二、完整源码（`src/`）

约 5500 行 Python + C++。

```
└── src/
    ├── README.md           ★ 源码说明（架构、核心算法、运行方法）
    ├── qt_app.py           主程序：PyQt5 界面
    ├── detector.py         检测引擎：YOLO + ROI + 停留计时 + 报警去重
    ├── evidence.py         取证模块：车牌识别 + 车色 + 车型 + 证据图合成
    ├── web_mirror.py       网页镜像服务
    ├── ui/                 样式表 + 三个自检脚本
    ├── config/             检测参数与 ROI 配置
    ├── launcher/           VS2022 C++ 启动器
    ├── build.spec          PyInstaller 打包配置
    └── pyi_hooks/          打包用的两个自定义 hook
```

**快速运行：** 进入 `src/` 目录，双击 `run.bat`（会自动找 Python、自动补装依赖）。

> 源码细节见 **[src/README.md](src/README.md)** —— 里面写了核心算法实现、
> 为什么用"底边中点"而不是"框交叠"、车牌防误报的双重校验、
> 以及三个自检脚本的用途。

> `yolov8n.pt`（YOLO 权重）和演示视频未上传，首次运行时自动下载 / 请自备。
